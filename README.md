# The Crazy Journal

> *Truth without guarantees. An uncompromising publication exploring cognitive anomalies, modern contradictions, risk, and human nature.*

## 📖 Features & Architecture
- **Framework:** Next.js 14 (App Router) + TypeScript + Tailwind CSS
- **Design System:** NileQuest Quarterly-inspired aesthetic with Midnight Obsidian Slate (`#0A1120`) and Fiery Ember Vermilion (`#F05438`)
- **Reading Experience:** Responsive left-floated image wraps, pull quotes, interactive sparring chamber, and floating audio narration dock
- **Content:** Markdown-driven essays with structured frontmatter metadata

## 🚀 Deployment
Configured for zero-config deployment on [Vercel](https://vercel.com) with custom domain support for `crazyjournal.ng`.
